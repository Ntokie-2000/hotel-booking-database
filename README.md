# 🏨 Hotel Booking System

##  Overview
The Hotel Booking System is a web-based application that allows users to search, view, and book hotel rooms online. It also includes an admin panel to manage rooms, users, and bookings. The project uses **MySQL** for database management.

---

##  Features
- User registration and login  
- Search and view available hotels/rooms  
- Room booking system  
- Booking confirmation  
- Admin dashboard for managing rooms and bookings  
- MySQL database integration  

---

##  Technologies Used
- HTML  
- CSS  
- JavaScript  
- PHP / Node.js (choose your backend)  
- MySQL
